vLLM — I fixed a bug inside an LLM inference engine.

vLLM is a high-performance LLM inference and serving engine used across AI platforms for memory-efficient request scheduling and paged KV cache management.

01
BUG
In SchedulingPolicy.PRIORITY, request preemption caused request index misalignment in waiting queue under KV cache pressure, silently skipping requests.
02
INVESTIGATION
Traced scheduler preemption bookkeeping in vllm/core/policy.py to analyze queue index mutation across eviction cycles.
03
ROOT CAUSE
Preemption eviction shifted queue pointers without re-indexing waiting requests in strict priority queue order.
04
FIX
Corrected preemption index re-calculation logic to preserve exact priority queue ordering without dropping pending requests.
05
TEST
Authored PyTest regression unit tests reproducing KV cache preemption scenarios under priority scheduling.
06
MERGED
Merged upstream into core repository: PR #49206
